Image protection:
The pages mark displayed photos as non-draggable/non-selectable and block the context menu on them. This is a deterrent only. Any image served on a public website can ultimately be captured, downloaded through developer tools, or screenshotted. No public HTML/CSS/JavaScript implementation can make an image truly uneditable.
